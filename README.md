# neuro-paper-skills

A trimmed copy of 10 skills from [K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)
(MIT license, copyright K-Dense Inc., see LICENSE.md), taken from commit 92ace75 (2026-10-05).

The full repository is over the 100 MB GitHub-import limit, so this repo keeps only the skills
used for writing a computational neuroscience paper:

| Skill | Use |
|---|---|
| scientific-writing | Draft and audit manuscript sections, claims vs. evidence, reporting guidelines |
| literature-review | Systematic literature search and synthesis |
| paper-lookup | Search PubMed, arXiv, bioRxiv, OpenAlex, Crossref |
| citation-management | DOI to BibTeX, citation validation |
| scientific-critical-thinking | Stress-test claims, confounds, alternative explanations |
| peer-review | Self-review the manuscript before submission |
| scientific-visualization | Publication figures (Nature-style mplstyle, palettes, export) |
| statistical-analysis | Test selection, assumption checks, reporting |
| neuropixels-analysis | Extracellular ephys / spike sorting (SpikeInterface) |
| nwb-conversion | Convert sessions to Neurodata Without Borders |

Delete any skill folder you don't need.
